# VanGuard — Get-First-Users Plan (2 weeks)

**Reality:** the app is live and takes payment; it has **zero users because it's never been shown to caterers.** This is a distribution problem, not a product problem. Fix that before polishing UI — real users tell us what to polish.

## The loop
**Value (free checklist) → 10–20 trials → honest feedback → fix the top 3 friction points → convert + referrals.**

## Week 1 — put it in front of people (needs NO deploy)
- [ ] Turn `LEAD_MAGNET_food-safety-checklist.md` into a clean branded **PDF** (ask Rook — can render one).
- [ ] Join 6–10 UK mobile-catering / street-food Facebook groups; read each group's rules.
- [ ] Post **POST A** in 2–3 groups (stagger, not all at once). Reply to every comment; DM the checklist.
- [ ] Set up / claim the **Google Business Profile** for VanGuard.
- [ ] List on 2–3 free SaaS directories (Capterra, GetApp, SaaSHub) — slow organic, do once.
- **Target: 30+ checklist requests → 8–12 trials started.**

## Week 2 — feedback & convert
- [ ] Post **POST B / POST C** in the next groups.
- [ ] Run the feedback DMs (script #3) with every trial user. Log everything in `FEEDBACK_LOG.md`.
- [ ] Rook ships the **top 3 UI fixes** users actually tripped on (deploy via `netlify deploy --prod`).
- [ ] Convert engaged trials (script #4); ask happy users for referrals (script #5).
- **Target: first paying customer; a ranked list of what to build next.**

## Division of labour
- **Rook (agent):** PDF lead magnet, all copy, directory listings research, UI fixes, deploys, feedback logging, drafting replies.
- **Daniel (human):** the actual Facebook posting/DMs from your account (I can't post as you), and the yes/no calls. ~20–30 min/day of posting + replying is the whole ask.

## Honest scoreboard (not vanity metrics)
Track weekly: checklist requests → trials started → active users (logged ≥1 record) → feedback items → paying. If trials start but nobody logs a record, the problem is onboarding UI. If nobody even requests the checklist, the problem is the post/channel. Let the numbers tell us where to work.

## What this is NOT
Not "polish the UI for a week and hope." Not paid ads. Not cold-calling. Value-first posting + honest DMs + fast fixes — inside your stated comfort zone.
