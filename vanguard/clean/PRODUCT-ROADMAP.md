# VanGuard Clean — Product Roadmap

## North-star outcome
A commercial cleaning company should be able to open VanGuard Clean, record a completed clean with proof, and send a professional report to the client in minutes.

## Phase 1 — Demand capture
- [x] Early-access waitlist landing page
- [x] Secure waitlist submission function
- [x] Waitlist database schema
- [ ] Connect production Netlify environment variables
- [ ] Run Supabase waitlist SQL
- [ ] Test live signup end-to-end
- [ ] Start direct outreach to commercial cleaners

## Phase 2 — MVP activation
- [ ] Country selection during onboarding
- [ ] Business profile
- [ ] Customer/site creation
- [ ] Checklist templates
- [ ] Custom checklist builder
- [ ] Start/continue cleaning record
- [ ] Pass / fail / N/A item results
- [ ] Notes and corrective actions
- [ ] Photo evidence upload to private storage
- [ ] Client sign-off

## Phase 4 — Retention

- [ ] Client report sharing

- [ ] Offline-friendly record capture

## Phase 5 — International growth
- [x] Country-neutral data model
- [x] GB / US / CA / AU configuration foundation
- [x] International starter template pack
- [ ] Localised onboarding copy
- [ ] Localised report formatting
- [ ] Additional languages based on demand

## Product discipline
Do not add payroll, accounting, invoicing, HR, route optimisation, full CRM or other broad back-office features until customers repeatedly ask for them and there is a clear retention/revenue case.

Every new feature should primarily improve one of: **discovery, activation, payment, retention or referral.**
